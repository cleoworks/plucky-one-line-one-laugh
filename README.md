One Line, One Laugh — a program that writes one funny line of text (at most 200 characters) to `/output/entry.txt`. The line is the whole entry: a printer that jammed one time too many gets its obituary printed. The write is atomic (temp file + rename) and verified byte-for-byte, so the file on disk is exactly the line — 52 ASCII characters, no trailing newline.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
